# Robinson Crusoe Shipwrecked - Web Port

A Java-to-HTML5 web port of the Robinson Crusoe Shipwrecked game, bundled and deployed via npm.

## 🎮 Play Online
Access the live version here: 
👉 [https://bigzeex.github.io/robinson-crusoe-shipwrecked-webport/](https://bigzeex.github.io/robinson-crusoe-shipwrecked-webport/)

## Tech Stack
* Java ported to HTML5 / Web
* NPM Build Tools & Bundler
* GitHub Pages & Actions for CI/CD
